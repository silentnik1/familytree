# Родовід Курусів — с. Розлуч

Інтерактивне родинне дерево: 7 поколінь, шлюбні записи парафіяльних реєстрів, клікабельні картки з деталями.

## Що всередині

- `index.html` — розмітка сторінки
- `style.css` — оформлення (стиль старої метричної книги)
- `data.js` — усі дані дерева (згенеровано з вашого файлу `Микола_Курус.xlsx`)
- `script.js` — логіка: рендер карток, зум/панорама, пошук, модальні вікна записів

## Приватність

Останні лінії показані лише ініціалами — повні імена в публічний файл не потрапили.
